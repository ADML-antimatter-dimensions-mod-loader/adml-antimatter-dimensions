ADML API v1.0 完全リファレンス (Legacy)

レガシー仕様: API v1.0は、ADML初期リリースにおける基盤API仕様です。単一プラグインのパッチ適用とローカルストレージを提供していましたが、依存関係解決やセーブデータの自動同梱機能はありません。新規開発では API v1.1 の使用を強く推奨します。

1. ライフサイクルとプラグイン構造

API v1.0のプラグインは、class Plugin 構造を持ち、constructor(api) を通じてインスタンス化されます。モジュールの読み込み時（onload）とアンロード時（onunload）のシンプルなライフサイクルを持ちます。

class Plugin {
  constructor(api) {
    this.api = api;
  }
  onload() {
    this.api.notify("API v1.0 プラグインが有効化されました");
  }
  onunload() {
    this.api.notify("API v1.0 プラグインが無効化されました");
  }
}

2. API v1.0 公開メソッド一覧（全網羅）

メソッド / プロパティ引数型説明と戻り値
api.patch(targetObj, methodName, wrapperFn)ゲームオブジェクトの指定メソッドをフック・拡張します。
api.addStyle(cssString)ページ内にスコープ付きCSSスタイルシートを動的に注入します。
api.storage.get(key)プラグイン専用のローカルストレージから指定キーの値を取得します。
api.storage.set(key, value)プラグイン専用のローカルストレージへ値を保存します。
api.notify(messageString)ゲーム画面上に通知トーストポップアップを表示します。
api.updateUI()ゲームのUI再描画および更新イベントを手動でトリガーします。

3. Manifest.json (v1.0) の仕様

API v1.0で記述する manifest.json の必須フィールド構成です。

{
  "manifestVersion": 1,
  "id": "my.legacy.plugin",
  "name": "Legacy Sample Mod",
  "version": "1.0.0",
  "apiVersion": "1",
  "author": "Developer",
  "description": "API v1.0 compatible legacy plugin",
  "main": "plugin.js"
}
