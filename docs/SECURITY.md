# ADML セキュリティガイド

ADMLプラグインは、ゲームページと同じブラウザコンテキストでJavaScriptを実行します。Shadow DOMによるUI分離や検査画面は表示上の衝突を減らしますが、悪意あるコードを完全なサンドボックスへ隔離するものではありません。

## インストール前の確認

まずZIPの取得元、リポジトリの所有者、manifestのID・作者・説明・バージョンを確認してください。`root.json` は配布カタログであり、安全性を保証する署名ではありません。ZIPを `INSPECT` で開き、manifestとファイル一覧を確認してから明示的に `ENABLE` してください。

## 危険な可能性がある処理

次の処理を含むMODは、目的と範囲を理解できる場合だけ使用してください。外部URLへの通信、ゲームセーブやlocalStorageの読み取り、既存メソッドのパッチ、動的コード生成、ユーザー入力のHTML挿入、他MODコードの読み取り、過剰なタイマーやMutationObserverの登録は、ゲームデータやプライバシーに影響する可能性があります。

## セーブのインポート

MOD領域を含むセーブをインポートする前には、危険性を知らせる確認ダイアログを表示します。承認しない限り、MODコード・有効化状態・MOD storageを適用してはいけません。承認した場合も、インポート後は有効化一覧とmanifestを再確認してください。

## 依存関係と互換性

manifestの `dependencies` と `compatibility` を確認し、依存MODが不足している場合や対象バージョンが一致しない場合は有効化しないでください。API v1.1のフィールドは、ローダーが検証を提供している場合その結果を使用し、未対応の旧版ではプラグイン側でも互換性を検査してください。

## 報告と復旧

不審な動作がある場合はMODを無効化し、ブラウザの開発者コンソールに表示されたエラー、manifest、取得元URL、再現手順を記録してください。セーブを復旧する前に、信頼できるバックアップへ戻してください。サイトデータを削除すると、ゲームの進行やインストール済みMODが消える場合があります。

> **原則:** 公開カタログに存在することは、信頼できることを意味しません。コードを読めないMODは有効化しないでください。
