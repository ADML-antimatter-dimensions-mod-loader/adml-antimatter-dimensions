ADML API v1.0 リファレンス（旧仕様）

注意 (Legacy): API v1.0 は初期のZIPプラグインシステムで採用されていた旧バージョンです。現在は依存関係・互換性チェックやセーブ自動統合を備えた API v1.1 への移行が推奨されています。

1. 概要と特徴

API v1.0 は、基本的なパッチ適用（patch）、スタイル注入（addStyle）、簡易ストレージ（storage）、および単体ZIPの読み込みをサポートしていた最初の安定バージョンです。複数のMOD間での依存関係解決や、ゲームセーブデータへのMOD本体の自動同梱機能は含まれていませんでした。

2. API v1.0 のメソッド一覧

メソッド名引数説明
api.patch(target, method, wrapper)ゲーム本体のメソッドをラップします。
api.addStyle(css)専用スコープ付きCSSを注入します。
api.storage.get(key)プラグイン設定を取得します。
api.storage.set(key, value)プラグイン設定を保存します。
api.notify(message)画面にトースト通知を表示します。
api.updateUIなしUIの更新を要求します。

3. v1.0 プラグインのサンプル

class Plugin {
  constructor(api) {
    this.api = api;
  }
  onload() {
    this.api.notify("v1.0 plugin loaded");
  }
  onunload() {}
}
