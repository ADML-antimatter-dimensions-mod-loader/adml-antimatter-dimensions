ADML API v1.0 Reference (Legacy)

Legacy Specification: API v1.0 is the initial plugin standard for ADML. It provided basic method patching and local storage but lacked dependency resolution and automatic save bundling. Developers are strongly encouraged to upgrade to API v1.1.

1. Lifecycle & Plugin Structure

API v1.0 plugins use a class Plugin structure instantiated with constructor(api), offering simple onload and onunload lifecycle hooks.

class Plugin {
  constructor(api) {
    this.api = api;
  }
  onload() {
    this.api.notify("API v1.0 plugin loaded");
  }
  onunload() {
    this.api.notify("API v1.0 plugin unloaded");
  }
}

2. API v1.0 Method Reference

Method / PropertyArgumentsDescription
api.patch(targetObj, methodName, wrapperFn)Hooks and wraps target game methods.
api.addStyle(cssString)Injects scoped CSS styles into the document.
api.storage.get(key)Retrieves plugin configuration from local storage.
api.storage.set(key, value)Saves configuration into plugin storage.
api.notify(messageString)Displays a toast notification on screen.
api.updateUI()Triggers a manual UI refresh event.
