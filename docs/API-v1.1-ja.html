ADML API v1.1 完全リファレンス (現行標準)

標準仕様: API v1.1は、依存関係管理（dependencies）、互換性検証（compatibility）、標準セーブへのMODデータ一括同梱、エンドゲーム拡張、MOD Forge、多言語化（i18n）を網羅した強力なプラットフォームAPIです。

1. ライフサイクルとグローバルランタイム

API v1.1では、インスタンスベースのプラグインに加え、ブラウザコンソールや外部ツールから安全に操作できるグローバルランタイム window.adml が提供されます。

// 実行中のMOD一覧やストレージ状態にアクセス
console.log(window.adml.mods);
console.log(window.adml.enabled);

2. API v1.1 公開メソッド・プロパティ一覧（全網羅）

カテゴリAPI / メソッド引数と詳細仕様
コアパッチapi.patch(target, method, wrapper) - ゲームの関数・メソッドを安全にラップします。
スタイルapi.addStyle(cssText) - スコープ付きCSSをDOMに挿入します。
ストレージapi.storage.get / set(key) / (key, value) - プラグイン専用データの永続化。
イベントapi.on / api.onGameLoad(event, cb) / (cb) - ゲームイベントおよびロード完了フック。
UI & タブapi.notify, api.updateUI, api.injectData, api.registerTab画面通知、UI更新、カスタムタブ・データ注入を行います。
エコシステムapi.mods, api.endgame, api.github, api.forgeインストール済みMOD操作、エンドゲーム拡張、GitHub連携、Forge。
多言語化api.i18n, api.language辞書登録、動的DOM監視、アクティブ言語の切り替え。
ゲーム参照api.player, api.currency, api.db, api.dcゲーム内データや通貨・データベースへの読み取り専用getter。

3. Manifest.json (v1.1) と依存関係・互換性

API v1.1対応のプラグインマニフェストでは、他のMODへの依存関係や互換性を明示できます。

{
  "manifestVersion": 1,
  "id": "advanced.mod",
  "name": "Advanced Feature Mod",
  "version": "1.1.0",
  "apiVersion": "v1.1",
  "author": "Modder",
  "description": "API v1.1 advanced plugin with dependency checks",
  "main": "plugin.js",
  "dependencies": {
    "japanese-language-pack": ">=1.0.0"
  },
  "compatibility": {
    "minAdmlVersion": "2.2.0",
    "gameVersion": ">=1.0.0"
  }
}
