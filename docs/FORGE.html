ADML Mod Forge Guide

MOD Forge is an in-game developer studio that allows you to create derivative plugins ("mods of mods") directly from your browser without leaving the game [1].

How to Create a Derivative Mod

  1. Open the MODS manager in the game.
  2. Click FORGE MOD in the top action bar.
  3. Select Parent Plugin: Choose an already installed plugin (e.g., Auto Booster or Multiverse Echoes Lite) as your template/parent.
  4. Edit Metadata & Code: The editor will automatically populate with the parent's manifest.json and plugin.js source code. Modify the ID, name, version, and logic as needed.
  5. Export ZIP: Click EXPORT ZIP to generate and download your brand-new derivative plugin archive instantly.

The parent plugin remains untouched, ensuring a safe and iterative modding workflow.
