ADML API v1.1 リファレンス（現行標準）

現行標準: API v1.1 は、依存関係の自動検証（dependencies）、バージョン互換性チェック（compatibility）、標準セーブへのMODデータ自動統合、エンドゲーム拡張、および多言語化（i18n）を網羅した最新の標準API仕様です。

1. 主な新機能と改善点

  • 依存関係の検証: プラグイン同士の関係や必要バージョンを指定可能。
  • 標準セーブ統合: Export/Import saveの中にMODコード・設定・有効状態が安全に同梱。
  • 高度なAPI群: endgame、forge、github、i18n、injectData などの強力な拡張モジュール。

2. API v1.1 の全メソッド一覧

カテゴリメソッド / プロパティ説明
コアパッチapi.patch(target, method, wrapper)メソッドをラップし自動解除に対応します。
スタイルapi.addStyle(css)専用スコープ付きCSSを追加します。
ストレージapi.storage.get(key) / set(key, val)プラグイン設定を保存・取得します。
イベントapi.on(event, cb) / api.onGameLoad(cb)イベント購読とロード完了時実行。
UI拡張api.notify, api.updateUI, api.injectData, api.registerTab通知、データ注入、タブ登録。
エコシステムapi.mods, api.endgame, api.github, api.forgeMOD一覧、エンドゲーム、GitHub、Forge。
多言語化api.i18n, api.language言語パック登録・動的DOM翻訳。
ゲーム参照api.player, api.currency, api.db, api.dcゲームデータへの読み取りgetter。
