ADML API バージョン比較表 (v1.0 vs v1.1)

ADMLの初期バージョンである API v1.0 と、現在の標準である API v1.1 の機能差分および仕様の比較です。

機能 / 項目API v1.0 (Legacy)API v1.1 (Current Standard)
apiVersion値"1" または "v1""v1.1"
依存関係 (dependencies)非対応対応（自動検証・順序制御）
互換性 (compatibility)非対応対応（ADML/ゲームバージョンの制限）
セーブデータ統合個別ボタン・独立管理標準 Export/Import save への自動同梱
エンドゲーム拡張なしapi.endgame によるカスタムレイヤー追加
MOD Forge (派生作成)なしapi.forge による親MODからの派生ZIP生成
GitHub連携単純検索のみ固定Topic adml-plugin と root.json 連携
多言語化 (i18n)独自実装api.i18n による動的DOM監視と辞書置換
セキュリティ警告なしインポート時のコード実行警告ダイアログ

移行の推奨

新規プラグインやテンプレートを作成する場合は、必ず manifest.json の apiVersion を "v1.1" に設定し、必要に応じて dependencies や compatibility を記述してください。
