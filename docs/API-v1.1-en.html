ADML API v1.1 Reference (Current Standard)

Standard Specification: API v1.1 is the modern platform API supporting dependency management (dependencies), compatibility checks (compatibility), automatic save bundling, endgame layers, MOD Forge, and internationalization (i18n).

1. Global Runtime & Lifecycle

API v1.1 introduces window.adml runtime introspection, allowing developer access to active plugins, enabled states, and storage data directly from devtools.

console.log(window.adml.mods);
console.log(window.adml.enabled);
